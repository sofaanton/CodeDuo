# НарядAI · MVP+

Веб-прототип цифровых производственных нарядов для кейса АО «Костанайские минералы». Frontend: адаптивный SPA/PWA на HTML/CSS/ES6; backend: FastAPI, SQLite, WebSocket.

## Запуск на Windows

Откройте PowerShell в каталоге `naryad-ai` и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Откройте [http://localhost:8000](http://localhost:8000). API-документация FastAPI доступна на `/docs`, проверка API — `/api/health`.

На первом старте создаётся `backend/naryad.sqlite3` с тестовыми справочниками и 500 синтетическими нарядами за 90 дней. В данных специально выделены повторы на конвейере К-3, возвраты слесарю Петрову и аварии после ППР на дробилке. Чтобы сгенерировать базу заново, остановите сервер и удалите этот файл.


## Телефон и PWA

Интерфейс mobile-first. Для установки PWA, WebSocket, микрофона, системных уведомлений и доступа с телефона нужен HTTPS-origin; `localhost` подходит для разработки на том же компьютере. Для сервиса push в закрытом браузере необходимо настроить VAPID-подписки и внешний push provider; в демо доступны WebSocket-уведомления при открытом приложении и системные уведомления браузера.

## Границы прототипа

История и сотрудники синтетические. Демо-вход проверяет учётные данные, но не создаёт защищённые сессии и не заменяет авторизацию с правами доступа. ИИ-модули — локальные эвристики, а не производственная LLM: сравнение фото использует perceptual hash для сигнализации о почти одинаковых снимках, но не подтверждает устранение дефекта. Рейтинг рассчитывается по формуле качества 40%, срока 30%, объёма 20% и возвратов 10%. Аудит информационной безопасности и подключение реальной ERP не настроены; не используйте этот демо-сервер для персональных или производственных данных.
